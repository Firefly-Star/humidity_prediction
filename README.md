# Humidity Prediction

A machine learning project for humidity prediction using time series analysis.

## Description

This project analyzes and predicts humidity levels using various machine learning models. Implemented as Jupyter notebooks with data preprocessing, exploratory data analysis, model training, and evaluation.

## Structure

- `1.ipynb` — Data exploration and preprocessing
- `2.ipynb` — Model training and prediction

## Tech Stack

- Python
- Jupyter Notebook
- Pandas, NumPy
- scikit-learn / TensorFlow
- Matplotlib (visualization)
